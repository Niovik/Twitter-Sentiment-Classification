# Sentiment Classification on Twitter Data

This repository contains two assignments for the course Artificial Intelligence II (Deep Learning for Natural Language Processing) at the National and Kapodistrian University of Athens (NKUA).

Both assignments use an English-language Twitter dataset, where each tweet is labelled as positive or negative. The dataset is included in the `data` folder.

- Sentiment classification using Logistic Regression and TF-IDF
- Sentiment classification using Feedforward Neural Networks and Word2Vec
